# Archive

Superseded documents live here, kept for history. Nothing in this folder is part of the plan.

**Policy** ([PLAN.md §8](../PLAN.md#8-process)):

- A document moves here once its replacement has landed, not before.
- The moved document opens with a banner that names its replacement.
- Every link to it is updated in the same commit; the docs-link test in CI catches any that are missed.
- The single-source lint does not check this folder.

No document has been archived yet. The first candidates are the legacy docs 06, 07, 10 and 11 and the stack docs, once TRK-17 to TRK-23 replace them.
